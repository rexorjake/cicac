2-Minute Free Firebase Setup

  1. Go to console.firebase.google.com, sign in with Google, and click Create a project (disable Google Analytics).
  2. In the left sidebar, open Build → Realtime Database, click Create Database, pick Singapore (or nearest region), and choose Start in test mode.
  3. Copy the database URL at the top of the Data tab (looks like https://your-app-default-rtdb.asia-southeast1.firebasedatabase.app).
  4. Paste it in the box on Device 1 (or hardcode it once into DEFAULT_FIREBASE_DATABASE_URL in sync_timer.html on GitHub Pages so every device connects automatically).
Note: Firebase Test Mode rules expire after 30 days. To keep it running permanently, open the Rules tab in Firebase Realtime Database and set { "rules": { "rooms": { ".read": true, ".write": true } } }.
